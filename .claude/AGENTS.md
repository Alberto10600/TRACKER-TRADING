## Most Relevant Agents for This Project

Given TRACKER-TRADING is a React + Electron trading journal app, the most useful agents are:

- **engineering-frontend-developer** — React components, UI implementation
- **engineering-backend-architect** — Electron IPC, data layer design
- **engineering-rapid-prototyper** — Fast feature iteration
- **engineering-senior-developer** — Code review, refactoring
- **testing-accessibility-auditor** — UI accessibility (WCAG)
- **testing-performance-benchmarker** — Rendering performance
- **testing-api-tester** — Data import/export validation
- **design-ui-designer** — Component design, visual consistency
- **design-ux-architect** — User flows, navigation
- **engineering-data-engineer** — Trade metrics, data pipelines
- **agents-orchestrator** — Coordinating multi-agent workflows

## Usage

Claude Code automatically discovers and can invoke these agents as sub-agents. You can also reference them explicitly:

```
Use the engineering-frontend-developer agent to implement the new chart component.
```
